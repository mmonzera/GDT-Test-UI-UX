# NUSAPLAY source

Static source for the NUSAPLAY gaming platform concept.

## Run locally

Serve the `dist` directory with any static file server, for example:

```bash
python3 -m http.server 4173 --directory dist
```

Then open `http://127.0.0.1:4173/`.

The `dist` folder contains the HTML entry point, CSS themes and motion styles, JavaScript interactions, and image/SVG assets.
